# pair-wise-yf-47 城市轨道交通突发停运应急协同

源提示词摘要：调度员、车站值班员、公交接驳负责人和客服主管协同处理突发停运，维护事故时间线、区段与车站状态、接驳计划、跨岗位确认和对外口径；弱网时需要使用缓存并把操作放入本地队列。

**新增：接触网检修「复电安全账」**（首页头部链接进入 `/safety`）——把事件收尾、区间停电、检修票、接地记录、人员进出接成一张账，配电室复电前逐项对账。

## 复电安全账规则

规则全部实现为纯函数（`lib/safety/`），不依赖 React，`tests/rules.test.ts` 逐规则覆盖：

- **复电前逐项对账，任一不过即禁止复电**（`复电对账` / `执行复电`）：
  - 事件已收尾；
  - 区间停电令在档（未复电）；
  - 票况：有效票过期/未到期/未完工都拦；票已完工且票账闭环才放行；
  - **票外作业**：仍挂设的接地线、仍在场人员所凭票号不是当前唯一有效票（排队票、过期票、作废票遗留）即拦；
  - 接地线已全部拆除；人员进/出流水轧差后无人在区间。
  - 对账通过后复电才会写复电时刻、有效票自动完工；复电操作不可重复执行。
- **同一区间只允许一张有效票**：新票按创建时刻排队（重算序号），只能队首激活，且必须先停电、票在有效期、必填项齐全；票完工后释放有效位，下一张补位。
- **换班**：当前班次下有效票与排队票一律作废（原票失效，记录原因），其余票按区间重算排队；接地与人员记录不随换班消失，继续接受对账。
- **断网票**：先存现场设备离线队列（`存离线票`），回网按票号合并（`回网同步`）——重复上传只认第一次（不覆盖任何字段、不计次），缺必填项进「待补」，补齐后才并入排队；排队顺序以现场创建时刻为准。

演示台提供「模拟时钟 +/−30 分」「在线/断网」「换班」开关，可完整走查上述场景。
